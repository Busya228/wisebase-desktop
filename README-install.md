# WiseBase CRM — установка (для пользователей)

1. Откройте страницу релизов: https://github.com/Busya228/wisebase-desktop/releases/latest
2. Скачайте нужный файл:
   - **Windows** — `WiseBase-CRM-Setup-<версия>.exe` (обычный установщик,
     **умеет обновляться сам** — рекомендуем его) или
     `WiseBase-CRM-Portable-<версия>.exe` (без установки, но и без
     автообновлений — обновлять придётся вручную).
   - **macOS Apple Silicon (M1–M4)** — `WiseBase-CRM-<версия>-mac-arm64.zip`.
   - **macOS Intel** — `WiseBase-CRM-<версия>-mac-x64.zip`.
3. Установите/распакуйте и запустите.

## Первый запуск

- **Windows**: SmartScreen покажет «Windows защитила ваш компьютер» —
  нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Это
  ожидаемо: приложение пока не подписано платным сертификатом.
- **macOS**: обычный двойной клик по `WiseBase CRM.app` в первый раз ничего
  не откроет (Gatekeeper). Нужно **правый клик по иконке → «Открыть»** →
  подтвердить в диалоге. Дальше приложение открывается как обычно.

## Дальнейшие обновления

Если вы поставили установщик (не portable) на Windows или собранную версию
на macOS — приложение само проверяет обновления при запуске и предложит
обновиться, когда выйдет новая версия: «Обновить» — перезапуск примерно за
10 секунд, «Позже» — напомнит через 4 часа. Ничего скачивать вручную не нужно.
На macOS без подписи Apple окно предложит скачать новую версию со страницы релизов.
