## Версия 29.1.0

### Что нового

- **Настройки приложения** — все функции из верхнего меню (обновление, масштаб, трей, горячие клавиши, версия) перенесены в Профиль → ⚙️ Настройки → «🖥️ Приложение»
- **Режим окна** — в настройках можно выбрать «Полный экран» (без рамки и панели задач) или «Обычное окно». При полном экране у верхнего края появляется панель с кнопками управления. Выбор сохраняется
- **Обновления приложения** — при выходе новой версии появляется окно «Доступна новая версия WiseBase CRM. Обновить?». Обновление ставится поверх уже установленного приложения без переустановки
- **Данные в реальном времени** — изменения коллег в клиентах, задачах, сделках и поездках появляются без перезагрузки. Соединение восстанавливается само после обрыва
- **Карточки клиентов** — убраны просроченные даты и «N дн без контакта» из общего списка, они остались внутри карточки
- **Вкладка «Отчёты»** — новый раздел внутри вкладки «Аналитика». Загружайте .xlsx-файл с данными раз в неделю — приложение покажет KPI-карточки, таблицу менеджеров с выполнением плана и С2, блок неотгруженных заказов. Переключатель периода (Месяц / Квартал / Год), навигатор по месяцам с пикером. Данные хранятся по периодам и не пропадают при перезапуске
